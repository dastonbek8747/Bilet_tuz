# Exam Ticket Generator

> A Tkinter desktop app that builds exam tickets from a question bank and exports them.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Pick a faculty and a study direction.
- Compose tickets from easy, hard and theory questions.
- Export the generated tickets.

## Tech Stack

| Layer | Technology |
|---|---|
| UI | Tkinter |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/exam-ticket-generator.git
cd exam-ticket-generator
python main.py
```

## Project Structure

```
main.py    # Tkinter UI and ticket logic
```
