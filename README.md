# 🎫 Bilet Tuz (Tkinter)

**Tkinter** asosida imtihon biletlarini tuzish uchun desktop ilova. Fanlar bo'yicha savollarni tanlab, bilet shakllantiradi.

---

## ✨ Imkoniyatlar

- 📚 **Fanlar tanlovi** (fakultet)
- 🎲 **Savollarni tanlash:** oson / qiyin / nazariy
- 🖥 **Grafik interfeys:** Tkinter
- 📄 **Bilet shakllantirish**

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Tkinter** | Desktop GUI |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/Bilet_tuz.git
cd Bilet_tuz
# Tkinter odatda Python bilan birga keladi
# Ubuntu: sudo apt install python3-tk
```

---

## ▶️ Ishga tushirish

```bash
python main.py
```
